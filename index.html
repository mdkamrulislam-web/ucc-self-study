How to use the guides

One idea per lesson

Read the highlighted box first. Everything below it builds that single idea, with slide or note references so you can check against the lecture material.

Tick as you go

Each guide has an “I’ve got this lesson” tick. Ticks are stored in your browser only, and the progress bars on this page read them.

Practise before peeking

Past-paper and exam-style questions sit near the end of each guide. Work them on paper, then open the worked solution.
